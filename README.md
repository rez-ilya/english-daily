# English Daily

Веб-приложение для ежедневных занятий английским по плану из `english-plan.json`:
11 недель, 66 учебных дней, 5 шагов в день. Работает без сервера: все данные хранятся
в браузере (IndexedDB). Устанавливается на телефон как приложение (PWA) и работает офлайн.

## Что внутри

| Экран | Что делает |
|---|---|
| **Сегодня** | тема недели и дня, 5 шагов с таймерами, оценка речи, доп. минуты, заметка, материалы; по субботам — самооценка IELTS |
| **Запись** | диктофон, записи привязаны к дню; сравнение контрольных записей |
| **Письмо** | текст дня со счётчиком слов и целью из плана, кнопка «Скопировать для проверки», архив текстов |
| **Ошибки** | журнал «ошибка → правильно → правило» с поиском; 5 последних показываются перед письмом |
| **Фразы** | словарь фраз, карточки «помню / не помню» (система Лейтнера: 1/2/4/8/16 дней), CSV для Anki; вкладка **ML & AI** — встроенная колода терминов |
| **Прогресс** | календарь-тепловая карта, серия дней, полные дни, % шагов, минуты, графики по неделям |
| **Данные** | экспорт и импорт всех данных в JSON (вместе с аудио) |

Все темы, шаги, критерии, материалы и даты контрольных записей берутся из `english-plan.json`.
Длительность таймера — первое число из подсказки шага (`"10 мин · …"`), цель по словам —
из задания дня (если там есть «N слов») или из `writingLength` недели.
После правки JSON пересоберите приложение (`npm run build`) или перезапустите `npm run dev`.

## Запуск на компьютере

Нужен [Node.js](https://nodejs.org) 20 или новее.

```bash
npm install
```

```bash
npm run dev
```

Откройте адрес, который покажет терминал (обычно http://localhost:5173).

Проверить продакшн-сборку (так же, как она будет работать на GitHub Pages, вместе с офлайн-режимом):

```bash
npm run build
```

```bash
npm run preview
```

### Открыть с телефона в той же Wi-Fi сети

```bash
npm run dev -- --host
```

Терминал покажет адрес вида `http://192.168.x.x:5173`. Страница откроется, но **микрофон и установка
PWA работают только по HTTPS** (или на localhost) — для полноценной работы с телефона выложите
приложение на GitHub Pages.

## Бесплатная публикация на GitHub Pages

1. Создайте аккаунт на [github.com](https://github.com) и новый **публичный** репозиторий,
   например `english-daily` (без README — он уже есть).
2. В папке проекта выполните (подставьте свой логин):

   ```bash
   git init
   ```

   ```bash
   git add .
   ```

   ```bash
   git commit -m "English Daily"
   ```

   ```bash
   git branch -M main
   ```

   ```bash
   git remote add origin https://github.com/ВАШ_ЛОГИН/english-daily.git
   ```

   ```bash
   git push -u origin main
   ```

3. На GitHub откройте репозиторий → **Settings → Pages** → в поле **Source** выберите **GitHub Actions**.
4. Откройте вкладку **Actions**: workflow «Deploy to GitHub Pages» соберёт и опубликует сайт
   (если он запустился до шага 3 и упал — нажмите **Re-run jobs**).
5. Через 1–2 минуты приложение будет доступно по адресу
   `https://ВАШ_ЛОГИН.github.io/english-daily/`.

Каждый следующий `git push` в ветку `main` обновляет сайт автоматически. Файл workflow лежит в
`.github/workflows/deploy.yml`. Пути в сборке относительные (`base: './'` в `vite.config.ts`),
поэтому название репозитория может быть любым.

> Данные хранятся в браузере каждого устройства отдельно и на GitHub не попадают.
> Чтобы перенести их на другое устройство — «Данные» → «Экспорт», затем «Импорт» на новом устройстве.

## Установка на телефон

- **Android (Chrome):** откройте сайт → меню ⋮ → «Установить приложение» / «Добавить на главный экран».
- **iPhone (Safari):** откройте сайт → «Поделиться» → «На экран Домой».

После первого открытия приложение работает без интернета (кроме ссылок на внешние материалы).
Обновления подтягиваются автоматически при следующем запуске с интернетом.

## Колода ML & AI на телефоне

Вкладка «Фразы» → **ML & AI** — та же колода, что в `anki-deck/` (164 термина × 2 карточки, картинки, озвучка
голосом телефона), работает офлайн и бесплатно на iPhone. Новых карточек в день — 5/10/15/20 (выбор на вкладке);
карточка «вспомнить» приходит на следующий день после «узнать». Прогресс хранится в приложении
(попадает в резервную копию) и не связан с Anki на компьютере.

Колода генерируется из `anki-deck/terms.py`: после правок выполните `python build.py` в папке `anki-deck` — он обновит
и `ML-AI-English.apkg`, и файлы для приложения (`decks/ml-ai.json`, `public/decks/ml-ai/`). Эти файлы нужно
закоммитить: GitHub Actions собирает сайт без Python.

## Резервная копия

Браузер может очистить данные сайта (например, при нехватке места или очистке истории).
Раз в неделю делайте экспорт: «Данные» → «Экспорт в JSON». На том же экране можно попросить
браузер хранить данные постоянно.

## Как устроен код

```
english-plan.json      план (единственный источник учебных данных)
src/plan/plan.ts       типы плана, поиск дня по дате, разбор минут и цели по словам
src/db/                IndexedDB (db.ts), перечитывание данных (useQuery.ts), экспорт/импорт (backup.ts)
src/lib/               даты, статистика, таймеры, запись звука, интервальное повторение
src/components/        общие элементы интерфейса
src/screens/           экраны приложения
src/styles.css         стили, светлая и тёмная тема (по системной настройке)
scripts/make-icons.mjs генерация иконок PWA (npm run icons)
```

## Импорт фраз в Anki

«Фразы» → «Словарь» → **CSV для Anki**. В Anki: «Файл → Импорт», выберите файл. Поля идут в порядке
«фраза, перевод, пример». Первые строки `#separator:comma` и `#html:false` — настройки импорта,
которые понимает Anki 2.1.55 и новее.

# Колода Anki «ML & AI English»

164 термина, коллокации и обороты по ML/AI → 328 карточек (две стороны у каждой записи):

1. **English → смысл**: термин, транскрипция, озвучка → картинка, перевод, определение, пример, коллокации, подсказка.
2. **смысл → English**: перевод, определение и пример с пропуском → вспомнить термин (есть подсказка по первым буквам).

Темы (теги `ml-ai::…`): ML basics, Training, Evaluation, Deep learning, LLMs & GenAI,
Verbs & collocations, Talking about tech, AI & society.

## Как добавить или исправить слова

1. Отредактируйте `terms.py` (термин в примере выделяется `**звёздочками**`).
2. Пересоберите (нужен Python 3 с пакетами `genanki matplotlib numpy`):

   ```bash
   python build.py
   ```

3. Импортируйте `ML-AI-English.apkg` в Anki (Файл → Импорт). Существующие карточки обновятся,
   прогресс повторений сохранится, дубликатов не будет.

Картинки рисует `images.py` (matplotlib), готовые файлы — в `build/media/`.

`build.py` заодно выгружает колоду для приложения English Daily: `../decks/ml-ai.json` и картинки в
`../public/decks/ml-ai/` (вкладка «Фразы» → ML & AI). После пересборки колоды пересоберите и приложение.
